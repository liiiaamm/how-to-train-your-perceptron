1. Classification as a smooth function

Binary classification assigns each object a label, 0 or 1, from its features. Written as a function,

\[ C : \mathbb{R}^n \rightarrow \{0,1\}. \]

Because \(C\) jumps from 0 to 1, it has no useful derivative and calculus cannot tell us how each feature influences the decision. So we replace it with a smooth approximation made of two parts:

  • a level function \(u : \mathbb{R}^n \to \mathbb{R}\), a linear combination of the features;
  • an activation function \(\phi : \mathbb{R} \to \mathbb{R}\), which turns that number into something between 0 and 1.
\[ C(x) \approx (\phi \circ u)(x), \]

and the object is assigned to the class of interest when \((\phi \circ u)(x) > \tau_0\) for a chosen threshold \(\tau_0\).

2. The perceptron

The perceptron uses the level function

\[ u(x_1,\ldots,x_n) = b + w_1 x_1 + \cdots + w_n x_n \equiv b + w^{\mathsf T} x, \tag{1} \]

with weight vector \(w = (w_1,\ldots,w_n)^{\mathsf T}\), input \(x = (x_1,\ldots,x_n)^{\mathsf T}\) and bias \(b \in \mathbb{R}\). The classic activation is the sigmoid,

\[ \phi(z) = \frac{1}{1 + e^{-z}}, \tag{2} \]

which is differentiable and moves smoothly from 0 to 1, passing through \(1/2\) at \(z = 0\). The model is

\[ F(x;\theta) = \phi\bigl(u(x;\theta)\bigr), \qquad \theta = (b, w_1, \ldots, w_n), \]

and training means choosing \(\theta\) to minimise the squared error over the \(N\) labelled examples:

\[ L(b, w_1, \ldots, w_n) = \sum_{k=1}^{N} \bigl(y_k - F(x^{(k)})\bigr)^2. \tag{3} \]

3. Derivatives and the gradient

Partial derivatives of \(u\)

\[ \frac{\partial u}{\partial b} = 1, \qquad \frac{\partial u}{\partial w_i} = x_i, \quad i = 1,\ldots,n. \]

Partial derivatives of \(F = \phi \circ u\)

By the chain rule,

\[ \frac{\partial F}{\partial b} = \phi'\bigl(u(x;\theta)\bigr), \qquad \frac{\partial F}{\partial w_j} = \phi'\bigl(u(x;\theta)\bigr)\, x_j. \]

Derivative of the sigmoid

\[ \phi'(z) = \frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}} \cdot \frac{e^{-z}}{1+e^{-z}} = \phi(z)\bigl(1-\phi(z)\bigr). \tag{4} \]

This is what makes the sigmoid cheap to train: its derivative is expressed through the value we have already computed.

Gradient of the loss

\[ \frac{\partial L}{\partial b} = -2 \sum_{k=1}^{N} \bigl(y_k - \phi(u(x^{(k)}))\bigr)\, \phi'\bigl(u(x^{(k)})\bigr), \] \[ \frac{\partial L}{\partial w_i} = -2 \sum_{k=1}^{N} x_i^{(k)} \bigl(y_k - \phi(u(x^{(k)}))\bigr)\, \phi'\bigl(u(x^{(k)})\bigr), \quad i = 1,\ldots,n. \]

Gradient descent repeats \(\theta \leftarrow \theta - \alpha \nabla L(\theta)\) with learning rate \(\alpha\).

4. AND and OR

Two-input logic gates are the smallest interesting case: four points in \(\mathbb{R}^2\).

\[ \text{AND: } (0,0)\mapsto 0,\; (0,1)\mapsto 0,\; (1,0)\mapsto 0,\; (1,1)\mapsto 1 \] \[ \text{OR: } (0,0)\mapsto 0,\; (0,1)\mapsto 1,\; (1,0)\mapsto 1,\; (1,1)\mapsto 1 \]

At the four inputs the model takes the values

\[ \begin{aligned} F(0,0) &= \phi(b), & F(0,1) &= \phi(w_2 + b), \\ F(1,0) &= \phi(w_1 + b), & F(1,1) &= \phi(w_1 + w_2 + b), \end{aligned} \]

so the two losses are

\[ L_{\text{AND}} = \phi(b)^2 + \phi(w_2+b)^2 + \phi(w_1+b)^2 + \bigl(1-\phi(w_1+w_2+b)\bigr)^2, \] \[ L_{\text{OR}} = \phi(b)^2 + \bigl(1-\phi(w_2+b)\bigr)^2 + \bigl(1-\phi(w_1+b)\bigr)^2 + \bigl(1-\phi(w_1+w_2+b)\bigr)^2. \]

The gradient written out for AND

\[ L_b = -2\Bigl( -\phi(b)\phi'(b) - \phi(w_2+b)\phi'(w_2+b) - \phi(w_1+b)\phi'(w_1+b) + \bigl(1-\phi(w_1+w_2+b)\bigr)\phi'(w_1+w_2+b) \Bigr) \] \[ L_{w_1} = -2\Bigl( -\phi(w_1+b)\phi'(w_1+b) + \bigl(1-\phi(w_1+w_2+b)\bigr)\phi'(w_1+w_2+b) \Bigr) \] \[ L_{w_2} = -2\Bigl( -\phi(w_2+b)\phi'(w_2+b) + \bigl(1-\phi(w_1+w_2+b)\bigr)\phi'(w_1+w_2+b) \Bigr) \]

Terms disappear from \(L_{w_1}\) and \(L_{w_2}\) because \(x_1^{(k)}\) or \(x_2^{(k)}\) is zero for those examples.

The gradient written out for OR

\[ L_b = -2\Bigl( -\phi(b)\phi'(b) + \bigl(1-\phi(w_2+b)\bigr)\phi'(w_2+b) + \bigl(1-\phi(w_1+b)\bigr)\phi'(w_1+b) + \bigl(1-\phi(w_1+w_2+b)\bigr)\phi'(w_1+w_2+b) \Bigr) \] \[ L_{w_1} = -2\Bigl( \bigl(1-\phi(w_1+b)\bigr)\phi'(w_1+b) + \bigl(1-\phi(w_1+w_2+b)\bigr)\phi'(w_1+w_2+b) \Bigr) \] \[ L_{w_2} = -2\Bigl( \bigl(1-\phi(w_2+b)\bigr)\phi'(w_2+b) + \bigl(1-\phi(w_1+w_2+b)\bigr)\phi'(w_1+w_2+b) \Bigr) \]

The decision line

With threshold \(\tau_0 = 1/2\), the boundary is where \(F = 1/2\), which happens exactly when \(u = 0\):

\[ b + w_1 x_1 + w_2 x_2 = 0 \quad\Longleftrightarrow\quad x_2 = -\frac{b + w_1 x_1}{w_2}. \]

For a general threshold \(\tau\) the line shifts to \(u = \log\frac{\tau}{1-\tau}\). With the trained parameters, this line separates the four points correctly for both gates.

Correction to the original report, which used the level curve \(u = 1/2\). The boundary of the classifier \(F > 1/2\) is \(u = 0\).

5. Why XOR fails

\[ \text{XOR: } (0,0)\mapsto 0,\; (0,1)\mapsto 1,\; (1,0)\mapsto 1,\; (1,1)\mapsto 0 \]

A single perceptron can only draw straight boundaries. The two positive points sit on opposite corners of the square, so any line that puts both on one side also takes at least one negative point with it. No choice of \((b, w_1, w_2)\) drives the error to zero. In practice, gradient descent settles near \(F \approx 1/2\) everywhere, with loss close to 1. The problem is the architecture, not the training.

6. The two-layer perceptron

Adding a layer removes that limit. With enough hidden units and a sigmoid activation, a multilayer perceptron can approximate any continuous function on a compact set (the universal approximation theorem). One extra layer is enough for XOR.

The idea is to run several perceptrons in parallel, turning the original features \(x\) into new ones, and then apply one more perceptron to those. The first block is affine,

\[ s = W^{[1]} x + b^{[1]}, \qquad s_i = \sum_{j=1}^{n} w^{[1]}_{ij} x_j + b^{[1]}_i, \]

followed by the sigmoid applied to each component,

\[ z = \Phi(s) = \bigl(\phi(s_1), \ldots, \phi(s_n)\bigr), \]

and an output perceptron on top:

\[ t = \sum_{i=1}^{n} w^{[2]}_i z_i + b^{[2]}, \qquad F(x) = \phi(t). \tag{5} \]

Since \(\Phi\) acts on each coordinate separately, its Jacobian is diagonal:

\[ D\Phi(s) = \operatorname{diag}\bigl(\phi'(s_1), \ldots, \phi'(s_n)\bigr). \]

7. Derivatives with a hidden layer

Output layer

\[ \frac{\partial F}{\partial b^{[2]}} = \phi'(t), \qquad \frac{\partial F}{\partial w^{[2]}_i} = \phi'(t)\, z_i. \]

Hidden layer

The chain rule passes through \(t\), then \(z_i\), then \(s_i\):

\[ \frac{\partial F}{\partial b^{[1]}_i} = \underbrace{\phi'(t)}_{\partial F/\partial t}\, \underbrace{w^{[2]}_i}_{\partial t/\partial z_i}\, \underbrace{\phi'(s_i)}_{\partial z_i/\partial s_i}, \qquad \frac{\partial F}{\partial w^{[1]}_{ij}} = \phi'(t)\, w^{[2]}_i\, \phi'(s_i)\, x_j. \]

Written fully in terms of the inputs and parameters:

\[ \frac{\partial F}{\partial w^{[1]}_{ij}} = \phi'\!\Bigl( \sum_{k} w^{[2]}_k\, \phi\bigl(\textstyle\sum_r w^{[1]}_{kr} x_r + b^{[1]}_k\bigr) + b^{[2]} \Bigr)\, w^{[2]}_i\, \phi'\!\Bigl(\textstyle\sum_r w^{[1]}_{ir} x_r + b^{[1]}_i\Bigr)\, x_j. \]

The gradient of the loss follows exactly as in section 3: multiply by \(-2\bigl(y_k - F(x^{(k)})\bigr)\) and sum over the examples. This is backpropagation, and it is what the interactive page runs to bend the plane.

8. Counting parameters

For two inputs, two hidden neurons and one output,

\[ \underbrace{W^{[1]}}_{2\times 2 \,=\, 4} + \underbrace{b^{[1]}}_{2} + \underbrace{w^{[2]}}_{2} + \underbrace{b^{[2]}}_{1} = 9 \text{ parameters.} \]

9. XOR with two layers

Trained by gradient descent, the 2-2-1 network from the report reaches

\[ \begin{array}{cc|c|c} x_1 & x_2 & F(x_1,x_2) & \text{class} \\ \hline 0 & 0 & 0.0065 & 0 \\ 0 & 1 & 0.9926 & 1 \\ 1 & 0 & 0.9926 & 1 \\ 1 & 1 & 0.0069 & 0 \end{array} \]

Over the unit square, \(F\) has two ridges, at \((0,1)\) and \((1,0)\), and two valleys, at \((0,0)\) and \((1,1)\). That is XOR. Seen from the hidden layer, the four points have been moved so that a single straight line separates them, which is what the last panel of the interactive page animates.
